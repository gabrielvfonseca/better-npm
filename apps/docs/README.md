# `@dash/docs`

Dash documentation site — Next.js application with MDX support.

## Overview

Next.js 15 documentation site with MDX support. Covers Getting Started (installation, quick start, configuration), Guides (creating packages, publishing, workspaces, CI/CD), and Reference (CLI, API, config file).

## Getting Started

```bash
npm run dev
# or
turbo dev --filter=@dash/docs
```
