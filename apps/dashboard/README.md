# `@better-npm/dashboard`

Bnpm admin dashboard — Next.js application.

## Overview

Next.js 15 application providing the admin dashboard UI. Built with `@better-npm/design-system`, `@better-npm/hooks`, `@better-npm/sdk`, and Recharts for data visualization.

## Getting Started

```bash
npm run dev
# or
turbo dev --filter=@better-npm/dashboard
```
