## Purpose

The five-step staged adoption path with copy-paste commands and per-step wins.

## Key points (from the design)

- 1 drop-in installer · 2 adopt manifest · 3 turn on policy · 4 native/dual publish · 5 drop the bridge (§20.4).
- Each step delivers value alone; none requires the next (§20.4).
