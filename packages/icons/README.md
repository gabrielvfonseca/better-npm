# `@better-npm/icons`

Icon name types and metadata for the Bnpm design system.

## Overview

Exports `IconName` union type covering 48 icon names (search, chevron, x, check, menu, home, user, settings, bell, mail, star, heart, share, download, upload, trash, edit, plus, minus, info, warning, alert-circle, check-circle, x-circle, copy, external-link, package, globe, lock, unlock, clock, calendar, filter, sort, more-horizontal, more-vertical, refresh-cw, loader, file, folder, tag, terminal, github, npm, and more) plus `ICON_NAMES` array and `IconProps` interface.

## Usage

```ts
import type { IconName, IconProps } from "@better-npm/icons";
import { ICON_NAMES } from "@better-npm/icons";
```
