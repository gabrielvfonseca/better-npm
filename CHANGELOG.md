## [0.0.0] — 2025-01-01

### Added

- Initial monorepo scaffold with Turborepo
- Package structure for TypeScript packages (`packages/*`)
- Crate structure for Rust crates (`crates/*`)
- Application layout (`apps/*`)
- Protobuf definitions directory (`proto/*`)
- Build tooling configuration (Biome, rustfmt, clippy)
- Development tooling setup (Just, Buf)
- Base TypeScript configuration with strict mode
- Base Rust workspace configuration (edition 2024)
