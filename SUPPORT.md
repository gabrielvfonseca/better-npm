## Bug Reports

Before submitting a bug report:

1. Search existing issues to see if the bug has already been reported.
2. Ensure you're running the latest version of Dash (`dash --version`).
3. Collect relevant information:
   - Dash version
   - Operating system and version
   - Bun version (`bun --version`)
   - Steps to reproduce
   - Expected vs. actual behavior
   - Logs or error messages

[Open a Bug Report](https://github.com/dashapp/dash/issues/new?template=bug_report.yml)

## Feature Requests

We welcome feature requests! Before opening one:

1. Search existing issues and discussions for similar ideas.
2. Consider how the feature fits into Dash's scope.
3. Describe the problem you're trying to solve, not just a solution.

[Submit a Feature Request](https://github.com/dashapp/dash/issues/new?template=feature_request.yml)

## Security Disclosures

**Do not open public issues for security vulnerabilities.**

Report security issues privately to **security@dash.dev**.

We will acknowledge receipt within 48 hours and provide a timeline for a fix.
Please see our [Security Policy](SECURITY.md) for details on our disclosure
process and bug bounty program (if applicable).

## FAQ

### What is Dash?

Dash is a fast, reliable JavaScript package manager written in TypeScript and
Rust. It aims to provide a modern alternative to npm, yarn, and pnpm with
better performance and developer experience.

### Is Dash a replacement for npm?

Dash is designed to be compatible with the npm registry and `package.json`
format. You can use Dash alongside npm, or as a drop-in replacement in most
projects.

### How do I migrate from npm/pnpm/yarn?

See the [Migration Guide](https://dash.dev/docs/migration) for step-by-step
instructions.

### Does Dash support workspaces?

Yes, Dash fully supports workspaces (monorepos). See the
[Workspaces Guide](https://dash.dev/docs/workspaces) for details.

### Is Dash open source?

Yes, Dash is open source under the MIT License. See the
[LICENSE](LICENSE) file for details.

### How can I contribute?

See our [Contributing Guide](CONTRIBUTING.md) for information on how to get
involved.

### Does Dash have a plugin system?

Plugin support is planned but not yet available. Follow the
[roadmap](https://dash.dev/roadmap) for updates.

### What's the performance difference compared to npm/pnpm/yarn?

Dash is significantly faster than npm and competitive with pnpm in most
scenarios. See our [benchmarks page](https://dash.dev/benchmarks) for detailed
comparisons.
